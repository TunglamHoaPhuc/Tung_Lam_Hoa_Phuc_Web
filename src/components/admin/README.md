# Admin Dashboard Components

Thu muc nay chua toan bo UI cho trang quan tri vien.

## Cac file chinh:
- `SpreadsheetPosts.tsx`      — Quan ly bai viet (~2900 dong, file LON)
- `SpreadsheetTongChi.tsx`    — Quan ly Tong Chi Tu Hoc (~222KB)
- `SpreadsheetGioiThieu.tsx`  — Quan ly trang Gioi Thieu
- `TongChiEditor.tsx`         — Editor inline cho Tong Chi
- `S3FileExplorerModal.tsx`   — Duyet file S3 tu Admin UI
- `ZenLotusBlockStudio.tsx`   — Custom block editor
- `PostFormEditor.tsx`        — Form editor bai viet

## Thu muc con:
- `layout/`  — AdminHeader, AdminSidebar, AdminShell
- `posts/`   — Sub-components tach ra tu SpreadsheetPosts
